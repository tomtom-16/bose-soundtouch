Modifier une enceinte

Recherche depuis le serveur de l’application. Choisissez une enceinte pour préremplir le formulaire, ou saisissez ses informations.

L’identifiant Bose (deviceID) est disponible sur http://IP-enceinte:8090/info. Le nom sert dans cette application. Enregistrer applique immédiatement les changements.

Presets

Choisissez la liste globale ou une enceinte, puis touchez un preset pour changer sa station. Chaque choix est enregistré immédiatement, sans lancer de lecture.

La liste globale sert à l’affichage « Toutes ». Chaque enceinte possède ses propres presets indépendants. « Sans affectation » désactive le preset dans la liste choisie.
